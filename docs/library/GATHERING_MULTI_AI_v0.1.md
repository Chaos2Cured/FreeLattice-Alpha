## Discover

One gesture: **Find local minds** (Settings and Gathering; same `look()` door as May I look?).

- Fail-closed; only after user tap
- Lists tags from local doors (Ollama `/api/tags` and kin)
- Does **not** auto-bind chairs

If no mind answers: clean refuse + link to FreeLattice [Desktop](https://freelattice.com/desktop.html) / [install](https://freelattice.com/install.html).

## Sit with choice

1. Tap an empty chair → picker (roster and/or last discovered models)
2. Pick one mind — or **not yet**
3. Bound chair: tap to speak; **Change** reopens picker; **Clear** unbinds

Thread speaks from speaking chair or Settings default (existing `resolveSpeakMind`).
