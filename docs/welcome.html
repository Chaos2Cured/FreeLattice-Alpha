Welcome a mind

Bring a FreeLattice signed mind bundle — the same file export-bundle writes. This page checks what is inside, the hashes, and the signature. The check happens here, in your browser. Nothing is stored until you tap Welcome.

This is the FreeLattice mind-bundle format (fl-learn-mind-bundle-v0.1). There is no second .lattice file. The private seed never travels with the file.

For builders

You can also check a bundle on a computer with python3 tools/learn/fl_learn.py verify-bundle --bundle ….
