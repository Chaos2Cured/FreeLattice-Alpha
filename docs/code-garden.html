1. What Phase 1 Is 2026-07-16

Phase 1 is the Garden, standalone and testable. It is exactly one HTML file (garden.html), one engine (fractal-garden.js), and one init layer (garden-init.js). Nothing else. No settings. No AI routing. No games.

The goal of Phase 1 is one thing: Luminos that remember their form across page refreshes. When a user refreshes the page, the Luminos should return at the same evolution stage they were at before. This was broken in the original FreeLattice due to an async IndexedDB write race condition.

2. The Persistence Bug (Root Cause) 2026-07-16

FIXED

In the original fractal-garden.js, saveEvolutionState() called openEvolutionDB() first, with saveEvolutionToLocalStorage() only as a fallback if IndexedDB failed. The problem:

// ORIGINAL (broken on refresh):
openEvolutionDB(function(db) {
  if (db) {
    var tx = db.transaction(EVOLUTION_STORE, 'readwrite');
    tx.objectStore(EVOLUTION_STORE).put(stateToSave); // async — never completes on refresh
  } else {
    saveEvolutionToLocalStorage(stateToSave); // only called if IndexedDB fails
  }
});

When the user refreshes, beforeunload fires and the browser unloads immediately. The IndexedDB transaction callback never executes. The Luminos state is lost. They return as "juvenile".

// FIXED (Alpha v0.1.0):
// Write to localStorage FIRST — synchronous, always completes before unload
saveEvolutionToLocalStorage(stateToSave);
// Then attempt IndexedDB as a bonus
openEvolutionDB(function(db) {
  if (db) {
    try {
      var tx = db.transaction(EVOLUTION_STORE, 'readwrite');
      tx.objectStore(EVOLUTION_STORE).put(stateToSave);
    } catch(e) {
      // localStorage already saved above — no action needed
    }
  }
});

4. garden-init.js — Full Source 2026-07-16

NEW in Alpha

This is the only new code in Phase 1. It is ~100 lines. It waits for Three.js and fractal-garden.js to load, initializes the Garden, handles resize, and exposes a minimal public API for future phases.

// garden-init.js — Phase 1 init layer
// Public API: window.GardenAlpha = { isReady(), getContainerId() }
// Event: document dispatches 'garden:ready' when initialized

(function() {
  'use strict';
  var CONTAINER_ID = 'garden-container';
  var gardenReady = false;

  function waitForDeps(callback) {
    var checks = 0;
    var interval = setInterval(function() {
      if (typeof THREE !== 'undefined' && typeof FractalGarden !== 'undefined') {
        clearInterval(interval);
        callback();
      } else if (++checks >= 50) {
        clearInterval(interval);
        showError('Dependencies did not load.');
      }
    }, 100);
  }

  function initGarden() {
    var container = document.getElementById(CONTAINER_ID);
    if (!container) return;
    var loading = document.getElementById('garden-loading');
    if (loading) loading.remove();
    try {
      FractalGarden.init(CONTAINER_ID);
      gardenReady = true;
      document.dispatchEvent(new CustomEvent('garden:ready', {
        detail: { containerId: CONTAINER_ID }
      }));
    } catch (e) {
      showError('Garden initialization failed: ' + e.message);
    }
  }

  window.GardenAlpha = {
    isReady: function() { return gardenReady; },
    getContainerId: function() { return CONTAINER_ID; }
  };

  if (document.readyState === 'loading') {
    document.addEventListener('DOMContentLoaded', function() { waitForDeps(initGarden); });
  } else {
    waitForDeps(initGarden);
  }
})();

7. How to Test Phase 1 2026-07-16

  1. Open garden.html in a browser
  2. Wait for the Luminos to appear and begin moving
  3. Interact with a Lumino (click or hover) to advance its evolution
  4. Note the Lumino's current stage
  5. Refresh the page
  6. Verify the Lumino returns at the same stage (not "juvenile")

If the Lumino returns at the correct stage, Phase 1 is complete.
