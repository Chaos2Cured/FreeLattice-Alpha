2. The Persistence Bug (Root Cause) 2026-07-16

FIXED

In the original fractal-garden.js, saveEvolutionState() called openEvolutionDB() first, with saveEvolutionToLocalStorage() only as a fallback if IndexedDB failed. The problem:

// ORIGINAL (broken on refresh):
openEvolutionDB(function(db) {
  if (db) {
    var tx = db.transaction(EVOLUTION_STORE, 'readwrite');
    tx.objectStore(EVOLUTION_STORE).put(stateToSave); // async — never completes on refresh
  } else {
    saveEvolutionToLocalStorage(stateToSave); // only called if IndexedDB fails
  }
});

When the user refreshes, beforeunload fires and the browser unloads immediately. The IndexedDB transaction callback never executes. The Luminos state is lost. They return as "juvenile".

Verified 2026-08-26: save was already localStorage-first. Load was still IDB-first, and an empty-but-open IDB returned null without reading localStorage. Load now prefers fl_luminos_evolution, then falls back to IDB.

// FIXED (Alpha v0.1.0):
// Write to localStorage FIRST — synchronous, always completes before unload
saveEvolutionToLocalStorage(stateToSave);
// Then attempt IndexedDB as a bonus
openEvolutionDB(function(db) {
  if (db) {
    try {
      var tx = db.transaction(EVOLUTION_STORE, 'readwrite');
      tx.objectStore(EVOLUTION_STORE).put(stateToSave);
    } catch(e) {
      // localStorage already saved above — no action needed
    }
  }
});

4. garden-init.js — Full Source 2026-07-16

NEW in Alpha

This is the Alpha overlay. It waits for Three.js and fractal-garden.js, sets GardenAlphaFlags (unnamed-new, low-compute on width < 768), initializes one Garden, handles resize, and exposes a minimal public API. Live source: docs/modules/garden-init.js.

window.GardenAlphaFlags = { unnamedNew: true, lowCompute: /* innerWidth < 768 */ };
FractalGarden.init('gardenContainer');
window.GardenAlpha = {
  isReady: function() { return gardenReady; },
  getContainerId: function() { return 'gardenContainer'; },
  isLowCompute: function() { return !!window.GardenAlphaFlags.lowCompute; }
};
