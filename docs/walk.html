A first walk

Eight steps. Each one is a single tap. Nothing here leaves your device, and nothing is pretended: if a room needs a mind and none is here yet, it says so.

  1. The Garden. The lights are doors. Tap a light to open it. Tap "the garden" to come back. The center light has no word on purpose.
    Open the Garden
  2. The Gathering. Tap "Find local minds", then "May I look?". The Tree looks only on this computer for a mind you already run (Ollama, LM Studio, llama.cpp, Jan, GPT4All, KoboldCPP). Remember one, and the other rooms wake up.
  3. No mind yet? Install Ollama, then run ollama run llama3.2. A model from Hugging Face works too, if it is a GGUF: ollama run hf.co/USER/REPO. Then go back to step 2.
  4. Chat. Talk with the mind you remembered. With no mind remembered, Chat stays quiet and tells you why.
  5. Nursery. An egg first. It grows slowly from what you keep on this machine, not from a clock. Grow holds the gentle training step.
  6. Settings. If your mind lives at a different address, put it here. Nothing is sent anywhere else.
  7. The galaxies. Use the arrows at the sides, or "galaxies" at the top. Art sings: Listen, Image, Chalkboard, poems. Workshop makes: benches, Agent, Trainer. Learn: the Round Table and Education. Research seeks: Chronal, Gauge, Love-logic, Simulation.
    Art · Workshop · Learn · Research
  8. Shared shoulder. What a person and a mind each carry here, in plain words.
    Read the shared shoulder

Some lights say "later". That is honest: the room is named, and its work is still coming. If you get stuck, open the Garden again and start at step 2.
